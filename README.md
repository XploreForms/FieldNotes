# Field Notes

Completion comments for Xplore field technicians. Answer the questions for the job, then copy the comment into FSL.

This folder is the whole site. There is nothing to build.

## Put it on GitHub Pages

1. Upload every file in this folder to the root of the repository, including `.nojekyll`.
2. In the repository, go to **Settings > Pages**. Under **Build and deployment**, choose **Deploy from a branch**, pick `main` and `/ (root)`, then **Save**.
3. After a minute the site is live at `https://<account>.github.io/<repository>/`.

## Install on an iPhone

Open the site in Safari with signal, tap **Share**, then **Add to Home Screen**. From then on it opens from the home screen and works with no signal.

## Updating

Replace `index.html` and `sw.js` with the new ones and commit. Phones pick up the new version the next time the app is opened with signal.
